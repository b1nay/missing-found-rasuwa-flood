# Missing & Found — Rasuwa–Bhotekoshi Flood

A searchable, multilingual list of missing and found persons from the Rasuwa–Bhotekoshi flood, built to help families and volunteers find each other quickly.

**Live site:** search the list, view stats on `/visualization`, and read `/information`.

## We need your help

If you have information about someone missing or found, or you're holding a more complete tracking sheet than what's here, please share it — a single detail can be the one that reunites a family.

- **Report or update a person** directly on the site: use the **Report Missing** / **Add Found** buttons, or **Mark Safe** / **Ask for Rescue** if you're reporting on yourself. These send straight to WhatsApp.
- **Have a data file** (a spreadsheet, another tracking sheet, photos, anything)? Open an [issue](../../issues) or a pull request with it, or reach out via the WhatsApp number used on the site. Please don't post anyone's personal details (phone numbers, addresses) in a public issue if you can avoid it — send it privately instead.
- **Found a bug, a wrong entry, or a way to make the site clearer?** Pull requests are welcome. `main` is protected — please open a PR rather than pushing directly.
